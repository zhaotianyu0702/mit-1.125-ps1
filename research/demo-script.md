# Five-minute demonstration script

AI Career Compass · MIT 1.125 PS1 · snapshot 2026-09-21 · fixed 70% skill target

This is a recording-ready run sheet, not a completed recording. The time blocks total 5:00. Spoken copy is approximate; leave time for the listed clicks and chart updates.

## Before recording

- Open the published site at `#landscape` in a desktop browser.
- Click **Reset**. In **Skill lab**, click **Clear skills**, then return to **Opportunity landscape**. This clears any retained role filter or device-local selection that would change the demonstration counts.
- Keep the five-slide presentation available as an optional introduction. Demonstrate the interactive site itself for most of the five minutes.
- Do not show other browser tabs, personal accounts or applicant information.

## 0:00–0:35 · Problem and intended user

**Show:** Opportunity landscape, all filters at their defaults.

**Say:** “AI Career Compass helps students who are beginning to explore AI careers understand the opportunity landscape and decide what to learn next. University career services and student groups can also use it to plan focused learning sessions. A list of job titles alone does not show how directions, locations and skills differ. This website turns a public posting sample into those comparisons, then lets a student test a skill-learning idea.”

## 0:35–1:20 · Data and collection

**Show:** The four summary indicators and the role distribution. Briefly point to the snapshot date.

**Say:** “This version freezes 852 US AI technical postings from 107 companies on September 21, 2026. The sources are official Greenhouse, Ashby, Lever and employer careers pages. The project merged source partitions, removed duplicates and normalized locations and skills. It keeps 795 automated-discovery records separately labeled from 57 curated source reviews. These counts describe the collected sample, not all AI vacancies. The sample covers several experience levels so that a new student can understand the broader career landscape.”

## 1:20–2:05 · Geographic and graduate comparisons

**Do:** Select **New York** under Location. Show the 225-posting slice. Click **Reset**. Briefly open the Experience level and Graduate evidence controls without changing the reset state.

**Say:** “Location filters update every chart together. New York appears in 225 postings in this sample. In the full dataset, 304 postings name at least one location outside California. A posting may name several places, so state totals overlap. The experience and graduate filters answer different questions: 66 postings receive the broad Entry label, while 42 explicitly identify a graduate pathway. An inferred Entry label alone does not establish eligibility. These distinctions help a student explore without treating missing evidence as a guarantee.”

## 2:05–3:30 · One reproducible skill experiment

**Do:** Open **Skill lab**. Confirm **All directions**, **All levels**, **Across the US**, **All postings**. Click **Clear skills**, then select **Python** and **Machine learning**. Click **Try adding LLMs**, inspect the preview, then **Add to my skills**.

**Say:** “I will use an illustrative student profile with Python and machine learning. This profile covers 74 of the 816 postings with tracked skills. The remaining 36 postings have no tracked skills and are not scored. The fixed target is 70 percent of each posting’s distinct tracked skills. A posting with five tracked skills therefore needs four selected skills.

“The recommendations show the marginal change from adding one skill. LLMs adds 93 postings that cross the target, bringing coverage from 74 to 167. Another 247 postings move closer while remaining below the target. These groups are separate. The preview and the applied result agree, and the recommendations recalculate after the selection changes. The five role bars show how the same profile differs across directions. Skill choices stay in this browser, and the target is a learning heuristic rather than a hiring score.”

## 3:30–4:20 · Two practical recommendations

**Do:** Expand **Project files**, open **Submission materials**, and show Main findings and Two decisions the data can inform.

**Say:** “The first recommendation is to compare locations beyond California before narrowing exploration. The 304 postings with a non-California location give students and career groups a concrete starting set.

“The second is to use separate learning tracks. SQL appears in 66 of 79 Data Science postings, while Kubernetes appears in 66 of 183 ML Infrastructure postings. A career group could run a SQL-focused data session and a Kubernetes-focused infrastructure session, then let students use Skill lab to choose a project suited to their current skills. These are suggestions supported by observed mentions, not proof that a particular course will improve hiring outcomes.”

## 4:20–5:00 · Evidence and limits

**Do:** Return to the site and open **Job postings**. Show the experience, skill and source columns. Return to **Submission materials** and point to the CSV, methodology, reflection and complete pack.

**Say:** “Every displayed posting remains inspectable, with its official source and recorded check date. The downloadable CSV tables support the charts, and the one-page method note explains collection and definitions. The reflection describes what the analysis cannot prove. The selected boards are not representative, skill extraction can miss terms, and required and preferred mentions are mixed. Missing skills do not mean no requirements. The value is a transparent way to compare directions and choose the next learning question.”

## Verification cues

- All filters reset: 852 postings, 107 companies.
- New York only: 225 postings. Reset before the skill experiment.
- Python + Machine learning: 74 / 816 scored postings.
- Add LLMs: +93 newly reaching target, 167 / 816 total, 247 more still below target.
- Full dataset findings: 304 non-California-location postings; 42 explicit graduate pathways; 66 Entry labels.
- Skill mentions: SQL 66 / 79 in Data Science; Kubernetes 66 / 183 in ML Infrastructure.
- Presentation materials and script are ready. A video file is not included; record separately if requested by the instructor.
